## О проекте

[Codebattle](https://codebattle.hexlet.io/) — игровая платформа с открытым исходным кодом от Хекслета, разрабатываемая силами комьюнити.

Суть игры: два программиста одновременно решают одну задачу на разных языках программирования. Побеждает тот, кто справится быстрее.

### Основные возможности

- Игра против другого пользователя, бота или друга по ссылке
- Оба игрока видят код друг друга в реальном времени и результаты тестов, могут менять язык во время игры
- Выбор задачи по уровню сложности или случайный подбор
- Задачи на русском и английском языках
- Наблюдение за чужими играми в режиме зрителя
- Чат для зарегистрированных пользователей
- Просмотр завершённых игр в записи
- Рейтинг игроков за неделю, месяц и всё время
